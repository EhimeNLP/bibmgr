# Slack app icon

`icon.png` is the default Slack app icon. It is a 512×512 PNG rendered from [`frontend/public/favicon.svg`](../../frontend/public/favicon.svg) for compatibility with Slack's app icon upload.

Upload `icon.png` from the app's **Basic Information** page when creating the app. To customize the icon, upload a square PNG, JPEG, or GIF between 512×512 and 2000×2000 pixels.
